# The Sukoon Spot
Official POS Billing & Customer Tracking Web Application for **The Sukoon Spot** (Massage Chair Lounge, Mumbra, Thane - 400612).

### Features:
* **POS Terminal & Pricing:** Fast billing for Full Body Massage Chairs, Eye Massagers, and Combos.
* **Instant WhatsApp Receipts:** Automatically generates formatted invoices and sends receipts directly to customers via WhatsApp.
* **Loyalty Program Integration:** Tracks visit milestones (3rd visit 25% off, 6th visit 50% off, 9th visit 100% free within 90 days).
* **Live Analytics & CSV Export:** Real-time revenue tracking, payment split (UPI/Cash), and one-click data export.
